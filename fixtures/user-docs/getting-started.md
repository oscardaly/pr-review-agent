# Getting Started

ListAid helps charity shops turn donated items into online listings.

## Installation

```bash
bun install
bun run dev
```

## Exporting donation data

Ops staff can export donation history from the admin dashboard under
**Settings → Data → Export**. Exports are generated as CSV and emailed to the
address on the account. There is currently no API endpoint for exports — the
dashboard is the only supported route.
